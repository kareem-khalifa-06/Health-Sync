📖 Understanding Agile & User Stories

Sprint: A time-boxed period (5–7 days) to complete a focused set of features. Like a mini-deadline to keep you motivated!

User Story: A feature from the user's perspective — "As a [role], I want [feature] so that [benefit]". Keeps you building what matters.

Tasks: The actual coding work, broken into small pieces (30 min – 3 hrs). Check them off as you go!

Acceptance Criteria: Conditions that must be met for the feature to be "done". Use these to verify your work.

🚀 How to Use This Tracker

  • Start with Sprint 1: Each sprint builds on the previous one.
  • Read the User Story first: Understand what you're building and why before writing code.
  • Check off tasks: Click a checkbox and your progress saves automatically!
  • Use the UI Designs tab: See exactly what each screen should look like before building it.
  • Test as you go: Don't wait until the end — test each feature as you complete it.
  • Commit frequently: Make Git commits after each task or user story.

⚙️ Project Setup Guide

Step 1: Create Angular Project

  • ng new healthsync --routing --style=scss
  • cd healthsync
  • ng add @angular/material

Step 2: Set Up JSON Server

  • Install: npm install -g json-server
  • Place the Project1_HealthSync_Data.json file in your project root
  • Rename it to db.json
  • Run: json-server --watch db.json --port 3000
  • API available at: http://localhost:3000

Step 3: Install Additional Dependencies

  • Chart.js: npm install chart.js ng2-charts
  • Date handling: npm install date-fns
  • Icons (optional): npm install @angular/material-icons

Step 4: Project Structure

  • Create modules: ng g module auth, ng g module dashboard, etc.
  • Create services in a services/ folder
  • Create models in a models/ folder
  • Create shared components in shared/ module

🎯 Pro Tips

Environment Variables: Create separate environment files for development and production API URLs.

Lazy Loading: Implement lazy loading for feature modules to improve performance.

Guards: Use AuthGuard and RoleGuard to protect routes.

Interceptors: Create an HTTP interceptor to add auth tokens automatically.

State Management: Services with BehaviorSubject are sufficient for this project. No NgRx needed initially.
